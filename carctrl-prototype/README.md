# carctrl prototype

Prototype for **carctrl** — en app for å søke, vurdere, prøvekjøre og sammenligne biler.

## Kjør lokalt

```bash
npm install
npm run dev
```

## Legg ut på GitHub

1. Opprett et nytt repo på GitHub, for eksempel `carctrl`.
2. Last opp filene i denne mappen.
3. Kjør prosjektet lokalt eller deploy via Vercel / Netlify.

## Innhold

- React + Vite
- Tailwind CSS
- Mockdata for biler
- Søk, statusfilter, shortlist og sammenligning
- Dark-first ctrl-universet-stil
- carctrl aksentfarge: `#FFD23F`
